OPEN IT
  Unzip, then open index.html in any browser. To put it online, upload ALL
  files to any web host (cPanel/public_html, Netlify, GitHub Pages, etc.).

PAGES
  Public (no password): index, about, services, gallery, contact, enquiry
  Staff portal (ID + password): login.html -> portal (dashboard), job log,
  daily returns, attendance, my account, admin panel (admin only)

ADMIN TOOLS ON THE PUBLIC SITE
  When signed in as administrator, a dark bar appears under the menu:
   - Insert header picture / Remove header picture
   - Upload logo / Reset logo
  On Home and Gallery pages, "Create picture holder" makes a new slideshow
  frame. Each holder has Add pictures / Manage / Delete. Pictures slide
  continuously with random transition effects.

IMPORTANT - HOW DATA IS STORED
  This version stores everything (jobs, returns, staff accounts, enquiries,
  pictures) inside the browser of the computer being used. So:
   - Use ONE computer/browser for the job log and admin work, or the data
     will not be shared between devices.
   - Admin Panel > Backup & restore: download a backup regularly.
   - Customer enquiries are also sent by WhatsApp/email buttons after
     submitting, because a customer's phone cannot save into your browser.
   - Passwords are checked in the browser, which is fine for a small shop
     but not bank-level security. A server/database version is needed for
     shared, secure multi-device use.
