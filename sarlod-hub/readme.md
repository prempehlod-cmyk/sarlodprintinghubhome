# SARLOD Printing Hub website

## Put it online (Netlify)
1. Upload this folder to a GitHub repository (or use the Netlify CLI: `npm i -g netlify-cli`, then `netlify deploy --prod`).
2. On netlify.com choose "Add new site > Import from Git", pick the repository. No build settings are needed (netlify.toml has them).
3. The online-saving service (netlify/functions) is then switched on automatically.

Plain drag-and-drop of the folder shows the website, but may not install the online-saving service. Use the Git or CLI route for online saving.

## First sign-in
Staff page: ID `ADMIN`, password `sarlod123`. Change it at once (Dashboard > Change my password).
Then add staff under Staff Accounts.

## What is saved where
Every change is saved on the device at once. When signed in and online it is also saved to the website's online store and shared with other staff devices.
